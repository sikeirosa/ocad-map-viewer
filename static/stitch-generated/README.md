# Écrans Stitch Générés - OCAD Map Viewer

Ces fichiers HTML ont été générés par le projet Stitch et représentent les différentes pages de l'application OCAD Map Viewer avec le design system appliqué (Style Terra & Forest).

## Fichiers Disponibles

### 1. `home-optimized.html`
**Accueil - Style Terra & Forest (Optimisé)**
- Dimensions: 2560×2048 (Desktop)
- Contient la liste des cartes disponibles et la zone d'importation
- Page d'atterrissage principale de l'application

### 2. `viewer-split.html`
**Visionneuse - Style Terra & Forest (Split View)**
- Dimensions: 2560×2048 (Desktop)
- Affiche la visionneuse avec vue divisée (carte OCAD + Street View)
- Contrôles de calibration et outils de navigation

### 3. `file-selection.html`
**Sélection de fichier - OCAD Map Viewer**
- Dimensions: 2560×2048 (Desktop)
- Interface de sélection et d'importation de fichiers PDF
- Zone de drag-and-drop pour l'upload

### 4. `import-modal.html`
**Modale d'importation - Style Terra & Forest**
- Dimensions: 2560×2048 (Desktop)
- Affiche une modale de progression d'importation
- Détails du traitement du fichier et statut

## Utilisation

Ces fichiers peuvent être utilisés pour :
- **Référence visuelle** du design généré par Stitch
- **Documentation** des écrans de l'application
- **Prototypage rapide** des interfaces
- **Tests** de compatibilité du design système

## Caractéristiques Techniques

- Utilise **Tailwind CSS** (CDN)
- Fonts Google: **Inter** et **Material Symbols Outlined**
- Design réactif avec configuration Tailwind personnalisée
- Thème clair (light mode)
- Palette de couleurs intégrée au système de design
